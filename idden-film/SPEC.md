# SPEC — 이든 브랜드 필름 v4 (약 51초)

사용자가 준 흐름: 여행지 플라스틱 → 지구 현황 → 이든의 제작 방식 → 제품 특징 → 나무 1만 그루.

LOOK: 흰 바탕 #FFFFFF, 짙은 초록 #193B2A, 보조 회녹색 #66716A, 옅은 세이지 #EEF0E9. 영문과 숫자 Outfit 500, 한글 Pretendard 600. 1080x1350, 30fps.
SOUND: 페이지 자동재생은 무음. 음악은 넣지 않음(별도 SNS용이면 추가 검토).
BANNED: 어두운 바탕에 떠다니는 작은 요소, 글로우, 카드 세 장 나란히, 매 장면 같은 등장, 착지 후 계속 움직이는 제목, 근거 없는 숫자.
